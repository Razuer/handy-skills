# Reproducible sample: split radiator-pipe rosette

Run from the skill root:

```bash
python scripts/example_rosette.py --out-dir /tmp/rosette-example
python scripts/audit.py /tmp/rosette-example/rosette_assembly.step --expected-solids 2 --check-intersections
python scripts/audit.py /tmp/rosette-example/rosette_left.stl /tmp/rosette-example/rosette_right.stl
python scripts/render.py /tmp/rosette-example/rosette_left.step /tmp/rosette-example/rosette_right.step --out-dir /tmp/rosette-example/renders --explode 9
```

The example deliberately uses:

- central nominal pipe Ø18 mm + radial clearance 0.1 mm → bore Ø18.2 mm
- front face circle Ø60 mm, thickness 4 mm
- a small seam between two halves
- two passive cylindrical alignment keys on the left and relieved pockets on the right
- front edge rounding, applied before splitting (to avoid intermittent split-edge fillet failures)
- separate STEP and STL for each half, plus assembled STEP

**Important:** The pins are *registration features*, not verified snap clips: they may need glue, a sleeve or redesign to retain parts against separation. No print-fit performance or snap force is claimed. Intended as a learning/QA sample, not a fully specified production radiator fitting.

## Acceptance table example

| Requirement | Method | Outcome to record |
|---|---|---|
| Ø60 envelope | STEP overall bbox XY | numeric |
| 18.2 mm bore | source formula + section measurement | numeric / explicitly checked |
| two independent parts | STEP solid count | numeric |
| no interference when assembled | boolean common-volume | numeric |
| no unsupported micro walls | slice + manufacturing review | inspected/not inspected |
| seamless appearance | front image at full resolution | subjectively evaluated |
| print fits Ø18 pipe | physical print and measurement | untested until verified |

Record exact CAD package version, nozzle/material and render version alongside any claim based on environment.

## CadQuery API examples: six independent, tested modeling idioms

Run:

```bash
python scripts/cadquery_recipes.py --out-dir examples/recipe-output
python scripts/render_recipe_gallery.py --input-dir examples/recipe-output --out-dir examples/recipe-output/renders
python scripts/audit.py examples/recipe-output/mounting_plate.step examples/recipe-output/mounting_plate.stl
```

The script exports a matching `.step` + `.stl` for each of:

1. `mounting_plate` — `.box`, selectors, `.fillet`, `.pushPoints`, `.hole`
2. `revolved_ring` — 2D profile with `threePointArc`, `.revolve`
3. `lofted_transition` — chained planar profiles with `.loft`
4. `swept_tube` — spline path and circular `.sweep`
5. `shelled_enclosure` — negative-thickness `.shell` with top face removed
6. `circular_pattern` — `.polarArray` of holes through a disk

All six were generated by CadQuery and audited as separate valid solids. Their rendered image gallery is at `examples/recipe-output/renders/recipe_gallery.png`; review it visually for intended geometry, not just file creation. The broader rosette example demonstrates separate parts, assembly-pose interference audit and front/back/exploded views. See [CadQuery API cookbook](cadquery-api-cookbook.md) for syntax and caveats.
